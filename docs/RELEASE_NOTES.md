## Ещё не выпущено (ветка `feat/prat`)

- **Формат `.prat`.** Дедупликация по содержимому, блоки zstd с чтением одного файла без распаковки всего, хэши BLAKE3,
  шифрование паролем (Argon2id + XChaCha20-Poly1305, имена и индекс тоже зашифрованы) и данные восстановления
  (Рида–Соломона) с командой `packrat-cli repair`. Описание: `docs/PRAT_FORMAT.md`.
- **Данные восстановления в обычном ZIP** (`--format zip --recovery N`): такой ZIP открывается любым архиватором, чинит
  его Packrat (`docs/ZIP_RECOVERY.md`).
- **Плагин `packrat7z.dll` для 7-Zip:** список, проверка, распаковка и запрос пароля для `.prat`
  (`scripts\install_7zip_plugin.ps1`, `docs/SEVENZIP_PLUGIN.md`).
- **7z:** фильтры BCJ для исполняемых файлов, уже сжатое кладётся как есть, сортировка по типу, словарь по уровню
  (16 МиБ на уровне 5, 64 МиБ на 9), крупные солид-блоки, параллелизм с учётом памяти, `--dict-mb`, `--solid-mb`.
  Исправлена ошибка: при пустом файле раньше нескольких каталогов 7-Zip отвергал созданный архив («Headers Error»).
  Исправлена ошибка: при некруглом словаре архив не читался.
- **zstd:** libzstd, уровни 1–9 вместо одного.
- **Распаковка:** каталоги проверяются один раз, буфер на поток; прирост 10–15 % на мелких файлах.
- **Интерфейс:** формат `.prat`, ползунок данных восстановления, пароль для `.prat`, ассоциация `.prat`.
- **Командная строка:** неизвестные опции отклоняются (раньше `--password abc` молча создавал архив без пароля).

Измерения и их оговорки — `docs/BENCHMARKS.md`. Проверено тестами (225), настоящим 7-Zip 26.01 и на реальных данных;
WinRAR для проверки не было.

## Packrat 0.5.0 — несколько архивов за раз, компактная распаковка, «Отправить»

- **Выделили много архивов — одно окно.** «Распаковать здесь», «Распаковать в…» и «Проверить» из меню Проводника обрабатывают все выбранные архивы по очереди и дают один итог. Битый архив не останавливает остальные; «Распаковать в…» спрашивает папку один раз.
- **Компактная распаковка из Проводника.** Маленькое окно с прогрессом; после чистой распаковки папка открывается, окно закрывается само. При проблемах остаётся отчёт.
- **Удаление архива после распаковки (по умолчанию выключено).** В корзину, только после полной успешной распаковки всего архива. Если файл нельзя отправить в корзину, Windows спросит про удаление насовсем.
- **«Отправить → Packrat — в архив».** Все выбранные файлы попадают в один архив. Ставится и убирается вместе с меню Проводника.
- **Windows 11.** В «Настройках» — переключатель классического контекстного меню (Packrat виден без «Показать дополнительные параметры»); откат снятием галочки, нужен перезапуск Проводника. Меняет меню для всех программ и остаётся после удаления Packrat.

Проверено тестами и в изолированной ветке реестра; в живом Проводнике и визуально компактное окно не проверялось.

**Файлы релиза:** `Packrat-Setup.exe`, `Packrat.exe`, `packrat-cli.exe`, `SHA256SUMS.txt`. Исполняемые файлы не подписаны (SmartScreen); телеметрии нет, единственный сетевой запрос — проверка новой версии (отключается в настройках).
